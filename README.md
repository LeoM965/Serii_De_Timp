# Serii De Timp (Time Series Analysis)

Acest proiect conține seturi de date și instrumente pentru analiza seriilor de timp, concentrându-se pe date demografice și statistice.

## Structura Proiectului

- `documents/`: Conține seturile de date în format CSV.
  - `exportPivot_AMG157G.csv`: Date statistice pe grupe de vârstă și sexe.
  - `exportPivot_IPC102A.csv`: Date adiționale pentru analiză.

## Date Incluse
Seturile de date acoperă intervale de timp lunare și includ diverse métrici procentuale pentru categorii demografice.
